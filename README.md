# 🎫 Ticket Management System

A full-stack web application built using Flask to manage student support tickets with role-based access.

## 🚀 Features
- Student & Admin login system
- Ticket creation with file upload
- Admin dashboard with:
  - Ticket filtering
  - Status updates
  - Search functionality
- Flash notifications (auto disappearing)
- Clean UI using Bootstrap

## 🛠 Tech Stack
- Python (Flask)
- SQLite
- HTML, CSS, Bootstrap

## ▶️ Run Project

```bash
pip install -r requirements.txt
python app.py
